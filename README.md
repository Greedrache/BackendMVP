# ⚙️ MVP Backend (MVP-O-Mat API)

**The logic and data engine behind MVP.**

This repository contains the backend and API services for MVP, specifically powering the **MVP-O-Mat** – an interactive tool that delivers political questions and evaluates user alignment.

🌐 **Connected to:** [mvp-politik.de](https://mvp-politik.de)

---

## 📌 About the Project

This backend serves as the core data provider for the MVP platform's interactive features. Its primary responsibility is managing, processing, and delivering the questions, positions, and evaluation logic for the **MVP-O-Mat**.

By separating the logic from the presentation, this API ensures fast response times, secure handling of the underlying dataset, and a robust architecture.

---

## ⚙️ Technologies

- **Python** (Core programming language)
- **Django / Django REST Framework** (Backend framework and API development)
- **SQLite / PostgreSQL / MySQL** (Database management for questions and alignment data)

True to the project's philosophy, the backend focuses on clean structures, scalability, and secure API delivery.

---

## 🚀 Features

- 🔌 **RESTful API Endpoints:** Delivers questions and metadata to the frontend via JSON.
- 🧮 **MVP-O-Mat Logic:** Processes user answers and calculates the matching percentage.
- 🔒 **CORS Enabled:** Secure and restricted communication, tailored for `mvp-politik.de`.
- 🛡️ **Django Security:** Built-in protection against common web vulnerabilities.

---

## 🌍 Deployment

The backend is live and hosted on an external server, fully integrated with the official frontend.
